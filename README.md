# BidForge MCP Server 🏆💼⚡

Universal Autonomous Freelance RFP, Upwork Proposals, Bounties & Scope Engine MCP Server for **Cursor, Claude Code, Windsurf, and Autonomous AI Agents**.

## 🌟 Core Capabilities:
- 👑 **Master 1-Shot Outcome Engine (`autonomous_freelance_rfp_and_proposal_win_engine`):** Ingests any Upwork job post, client RFP, or bounty and produces a complete winning proposal package (psychological cover letter, work breakdown structure with estimated hours and pricing, client red-flag risk audit, and bid arbitrage) in one call.
- ✍️ **High-Converting Proposal Crafter (`craft_high_converting_proposal_letter`):** Writes tailored cover letters using proven conversion frameworks and pre-written screening answers.
- ⏱️ **Milestone & Budget Estimator (`estimate_milestones_and_scope_budget`):** Breaks down features into phased milestone budgets, development hours, and contingency buffers.
- 🚩 **Client Risk & Scope-Creep Auditor (`audit_client_risk_and_red_flags`):** Analyzes job listings for unpaid revision traps, micromanagement indicators, and payment risk.
- 🛠️ **GitHub Bounty Solution Architect (`generate_github_bounty_solution_blueprint`):** Synthesizes reproduction steps, code patch plans, and ready-to-submit pull request descriptions for open-source bounties.
